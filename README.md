# FishingTime

海鸥港，电脑浏览器可玩的钓鱼 Alpha。

[打开网页版](https://nullumnomen.github.io/fishing-time-releases/) · [下载与版本说明](https://github.com/NullumNomen/fishing-time-releases/releases)

## 0.1.0-alpha.1

- 电脑浏览器：打开网页后点击「开始游戏」。WASD / 方向键移动，空格钓鱼，E 互动，Esc 菜单。
- Windows x64：解压整个文件夹，运行 `FishingTime.exe`，并让 `FishingTime.pck` 留在旁边。
- 暂未适配手机触屏。网页切到后台时游戏暂停。
- 浏览器进度保存在这个网站自己的存储里。清除网站数据前，请在 Esc 菜单下载存档备份。
- 同一版本的源码、许可证和校验值附在 [Release](https://github.com/NullumNomen/fishing-time-releases/releases/tag/v0.1.0-alpha.1)。源码使用 AGPL-3.0。
